

## Функции:
- Все типы сообщений пересылаются
- Ответы на сообщения работают
- Редактирование текста/подписей
- Полное редактирование сообщений в очереди 
- Добавление/удаление агентов поддержки специальной командой
- Список всех агентов поддержки
- Оставьте заявку в поддержку в отдельном чате
- Многоязычие и возможность легко добавить свой язык
- Регистрация ошибок

### Команды администратора:
| Команда        |  Описание                               |
|----------------|--------------------------------------------|
| `set_group`    | Настройте группу для получения уведомлений туда |
| `add_support`  | Предоставляет права пользовательского агента                |
| `del_support`  | Удаляет права агента у пользователя         |
| `get_supports` |  Получает текущий список агентов           |

### Команды агента:
| Команда  | Описание                         |
|----------|-------------------------------------|
| `break`  | Остановить текущий разговор с пользователем |

### Пользовательские команды:
| Команда  |  Описание                |
|----------|-----------------------------|
| `start`  |  Получить стартовое сообщение          |
| `get_id` | Соответствует вашему пользователю ID |

### Как работает бот:
1. Ваш клиент отправляет вопрос вашему боту
2. бот отправляет запрос на уведомление в личку вашей группы или администратора
3. Администратор или агенты могут подтвердить или отклонить апелляцию.
4. В случае отклонения апелляции пользователь получит специальное сообщение.
5. В случае подтверждения запроса пользователь и агент подключаются к совместному чату.

### Поддержка языков:
- Russion
> Если вы хотите добавить еще один язык, скопируйте любой соответствующий язык, переведите его и назовите каталог, указав свой язык и код страны. Например: ru-RU

## Требования:
- Docker `(or golang)`
- Docker-Compose `(or golang)`
- Makefile

## Установка:
1. Создать файл .env `cp .env.example .env`
2. Вставьте свой токен бота и идентификатор пользователя в `.env`. Set default language
3. Запустить бота:
    - С Докером: `make build`
    - Локальный с Go: 
      - `go mod download`
      - `go run cmd/bot/main.go`
